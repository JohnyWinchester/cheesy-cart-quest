# 🍕 Пицца Казань (MVP)

Веб-приложение для быстрого и удобного заказа пиццы и напитков с доставкой в Казани. Проект разработан в рамках курса по AI-инжинирингу с активным использованием AI-агентов (Lovable.dev) для генерации кода, тестов и документации.

## ✨ Основные функции
- **Каталог товаров**: фильтрация по категориям (Пицца, Напитки).
- **Умная корзина**: добавление, удаление товаров, динамический пересчет итоговой суммы.
- **Оформление заказа**: форма с валидацией данных и интеграция Яндекс.Карты (зона доставки).
- **Адаптивный дизайн**: корректное отображение на мобильных устройствах и десктопе (Mobile-first, Tailwind CSS).

## 🛠 Технологический стек
- **Frontend**: React, Vite, JavaScript (ES6+)
- **Стилизация**: Tailwind CSS
- **Иконки**: lucide-react
- **Тестирование**: Vitest / Jest
- **Инструмент разработки**: Lovable.dev (AI Agent)
